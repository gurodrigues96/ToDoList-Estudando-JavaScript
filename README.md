## 💻 Sobre o Projeto

Este projeto é uma aplicação simples de **Lista de Tarefas (ToDo List)**, criada como um exercício prático de desenvolvimento web. O foco principal é a manipulação do DOM e a aplicação da lógica de programação utilizando JavaScript puro, sem o uso de *frameworks* complexos.

### 📌 Funcionalidades

* Adicionar novas tarefas.
* Marcar tarefas como concluídas.
* Excluir tarefas.
* Persistência de dados (salvamento no Local Storage para manter as tarefas mesmo após fechar o navegador).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
